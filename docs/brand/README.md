# Brand

The mark is three nodes joined by the three kinds of edge the platform knows: a solid edge for
**asserted** facts, a double edge for **derived** ones and a dashed edge for **inferred** ones. It is the
legend of the whole Context Model, drawn as its signature.

| File | Use |
|---|---|
| `lockup-dark.svg`, `lockup-light.svg` | mark and wordmark; `-dark` ink for light backgrounds, `-light` ink for dark ones |
| `wordmark-dark.svg`, `wordmark-light.svg` | the name alone |
| `mark.svg` | the mark for light backgrounds (and anywhere a single icon is needed) |
| `mark-on-dark.svg` | the mark for dark backgrounds |
| `favicon.svg` | the mark, switching with the browser's colour scheme; copied to `web/app/icon.svg` |

## Colour

| Name | Value | Role |
|---|---|---|
| ink | `#1f2a44` | tile, wordmark on light |
| pale | `#e8eefc` | tile and wordmark on dark |
| derived | `#2f6fd6` (on light tile `#8fb4ff`) | the double edge |
| inferred | `#7a5ab8` (on light tile `#c3b0ff`) | the dashed edge |

The same three colours mean the same thing in the web UI: asserted, derived (blue), inferred (violet).

## Type

The wordmark is **Schibsted Grotesk Bold**, tracking -0.02 em, outlined into paths so the files need no
font (licence: SIL Open Font License 1.1, `OFL-SchibstedGrotesk.txt`). The files are generated by `gen.py`
from the font, so the lockup geometry stays exact: mark as tall as ascender to descender, centred on the
x-height, a gap of 0.32 em.

## Usage

Keep clear space of half the mark's width around the lockup. Do not recolour the edges independently:
their colours carry meaning. The marks identify this project; they are not part of the Apache-2.0 / MIT
licence of the code, so use them to refer to the project, not to brand your own fork.
